# Instruções do projeto

## Memória do projeto

- Antes de iniciar trabalho técnico, leia `PROJECT_MEMORY.md`.
- Ao concluir uma tarefa que estabeleça uma decisão, corrija um bug relevante, revele uma restrição importante ou deixe uma pendência, atualize a memória sem pedir que o usuário peça para “guardar”.
- Registre um resumo curto com data e, quando útil, motivo, efeito e referências a arquivos, testes ou documentação.
- Não copie conversas inteiras, segredos ou detalhes de implementação que o Git já registra. Se não houver conhecimento duradouro novo, não altere a memória.
- Para decisões com impacto futuro, crie um registro próprio em `docs/decisions/` e atualize `PROJECT_MEMORY.md` com o resumo e o link. Leia o índice e as decisões existentes antes de criar outro registro.
